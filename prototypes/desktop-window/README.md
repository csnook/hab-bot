# Desktop window prototype (throwaway)

A throwaway UI prototype for [Desktop window](https://github.com/csnook/hab-bot/issues/26). It is kept on this branch as a primary source and is not meant to be merged or built on.

- `index.html` is version 2: one window with Inbox, Calendar, Agenda and Board views, list and priority filters, a first-run tip, and the tray menu.
- `v1.html` is version 1: the three layouts that became the Inbox, Calendar and Agenda views, compared side by side.

Open either file in a browser. Both load Preact and htm from cdn.jsdelivr.net and use sample data, with the time fixed at Wednesday 30 September 2026, 17:40. Nothing is saved.

The decisions it settled are in the ticket's resolution comment.
